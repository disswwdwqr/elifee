# 全國電子商品與節能補助查詢原型

## 冷氣旺季備貨決策系統

另有獨立的冷氣備貨看板：[冷氣旺季備貨決策系統.html](冷氣旺季備貨決策系統.html)。它使用同資料夾的 products-data.js 顯示冷氣商品，提供 60／90／120 天需求試算、28／42／56 天備貨目標、季節指數與氣溫／促銷情境調整、補貨點與採購量建議，以及 SKU 風險清單。

直接開啟 HTML 即可使用；如需以本機伺服器開啟，可在此資料夾執行 python3 -m http.server 8000，再瀏覽 http://localhost:8000/冷氣旺季備貨決策系統.html。

目前商品主檔庫存與近 30 天銷量是模擬資料，季節指數、天氣係數與需求變異係數也是示範值；這是規則式試算原型，尚未訓練成 AI 預測模型。可匯入 UTF-8 CSV，以 date、product_id、sales 為必要欄位，on_hand、inbound 為選填欄位。銷售資料請提供逐日記錄，包含零銷量日期；系統以每個 SKU 最近 28 天銷量估算日均需求，至少需涵蓋 7 個日曆日，並以該 SKU 最新列的 on_hand、inbound 更新情境。尚未提供足夠銷售紀錄的 SKU 仍沿用模擬值。匯入後可下載補貨建議 CSV。正式導入前應接上 POS、ERP、供應商交期、促銷日曆和天氣資料，並以歷史資料回測校準。

## 冷氣換機需求預測系統

另有獨立的換機需求與產能試辦原型：[冷氣換機需求預測系統.html](冷氣換機需求預測系統.html)。它提供客戶設備 CSV 匯入、換機關注排序與人工覆核、臺南各區安裝需求估算、規劃產能缺口比較，以及 CSV 匯出。臺南市各區人口與戶數參考資料已預先載入。

開啟頁面會載入 148 筆虛構客戶設備與六個月內換機結果，以及 37 區的模擬月安裝紀錄和規劃產能；也可按「載入示範資料」重設示範內容。可分別下載 [模擬客戶設備與結果](冷氣換機_模擬客戶設備與結果.csv) 和 [模擬月安裝與產能](冷氣換機_模擬月安裝與產能.csv)，或以這些欄位建立自己的 UTF-8 CSV。客戶資料欄位為 customer_id、district、install_year、repair_count_24m、last_repair_date、warranty_expired、marketing_consent、replaced_within_6m；安裝資料欄位為 month、district、installations、planned_slots。

客戶關注分數是可解釋的規則式排序，並非已訓練的 AI 機率；結果標籤僅供檢視排序與歷史結果的關聯。模擬換機標籤依虛構設備年限、維修與保固條件產生，模擬安裝量依虛構季節係數產生，數值不能代表實際需求或預測準確度。區域預估以過去相同季節的安裝量為基礎。人口與戶數僅用於區域規模參考。所有匯入資料只在瀏覽器分頁記憶體處理，關閉頁面後清除；系統不會自動發送訊息或派工。正式導入前需用全國電子歷史購買、維修、安裝與產能資料校準並驗證。

***

這個靜態網站原型提供偏好測驗與商品推薦，可依商品類別、預算和挑選偏好推薦商品；也提供商品搜尋、商品清單、同類型商品比較、條碼掃描介面，以及節能補助資訊。

## 資料來源與欄位

- `products-data.js` 從 `outputs/01a1c936-e1cc-7ac1-abdb-07b83920b989/全國電子商品模擬資料.xlsx` 匯出 1,000 筆商品。相同資料也內嵌於 `index.html`，讓本機直接開啟頁面時能載入商品與規格。
- 資料包含 63 筆網站品項參考、1 筆指定商品頁參考，以及 936 筆模擬新增商品。
- 主要規格與功能／連線欄除指定商品頁參考項目外皆為模擬；庫存、近 30 天銷量和評分皆為模擬值。原始資料沒有商品條碼與能效級別。
- 商品介紹會直接顯示試算表中的主要規格和功能／連線，並依資料類型標示來源。
- 查詢商品後會在介紹下方按商品種類列出同類商品，例如手機、冷氣與冰箱，跨品牌及型號顯示；清單先顯示 6 款，可展開全部。也可從商品卡片與介紹加入最多 4 項商品，自選比較規格、價格與模擬指標。
- 因此，掃描相機介面目前不能將實體商品條碼配對到商品；商品查詢可使用模擬商品編號、品名、品牌或型號。
- `uma-style.css` 套用明亮黃橘、粗描邊、圓角標題與彩色資訊卡的視覺，參考 [JRA ウマジョブ](https://jra-fun.jp/umajob/) 網站。

## 開啟網站

商品查詢與商品清單使用各自獨立的搜尋欄位，清單另有分類和排序。保持 `index.html` 與 `uma-style.css` 在同一資料夾，直接開啟 `index.html` 即可檢視商品清單與手動搜尋。相機掃描需要瀏覽器支援 `BarcodeDetector`，並透過 HTTPS 或 localhost 開啟。可在此資料夾執行：

```sh
python3 -m http.server 8000
```

再瀏覽 `http://localhost:8000`。

## 商品資料更新

目前資料整理在 `products-data.js`，並同步內嵌於 `index.html`。更新試算表後需重新匯出並同步兩處資料。正式上線前需串接正式商品主檔與條碼資料，並建立價格、庫存及官方能效資料的更新流程。
